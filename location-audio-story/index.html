📍 スポット / Spots

⚙️ 設定 / Settings (GPS誤差対策)
ビル街でGPSが乱れても誤発動しないよう、①精度の悪い測位を捨てる、②位置を平滑化する、③円に「入る判定」と「出る判定」の半径を変える(ヒステリシス)、④連続して円内にいた時だけ発動する、の4段構えです。
✏️ スポット編集 (JSON) / Edit spots

name(名前), lat, lon, radius(m, 省略時は設定値), text(読み上げ文), audioUrl(音声ファイルURL, 省略時はtextを合成音声で読み上げ), lang(例 "ja-JP"), alt(高度m・省略可), altTol(高度許容差m, 既定20)。altを入れると高度が大きく違う場所(展望台と地上など)で誤発動しません。同じ場所で「＋現在地に追加」すると測定高度が自動記録されます。

🧪 シミュレーション / Simulation (GPSなしでテスト)

室内での動作確認用。ボタンでスポットへ仮想移動します。/ Test indoors by teleporting a fake position.

📜 ログ / Log
